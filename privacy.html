一、我们如何收集和使用您的个人信息

我们将在本政策中依次向您说明我们的产品与/或服务每项功能可能收集的个人信息范围、收集目的、收集方式，以及不提供您的个人信息可能导致的结果。请您知悉，您不提供各项功能实现所必要的对应信息时，仍然可以使用其他功能。

我们会遵循正当、合法、必要的原则，出于本政策所述目的，收集和使用您主动提供或因使用我们的产品和/或服务而产生的个人信息。如果我们将您的个人信息用于本政策未载明的其他用途，或基于特定目的将已收集的信息用于其他目的，我们将以合理方式告知您，并在使用前再次征得您的同意。您可通过《个人信息收集清单》查看详情。

1. 账号注册及登录

当您注册或者登录 dooo0t 账号时，您需要通过手机号码创建账号并完成注册。手机号码是履行国家法律法规关于网络实名制要求的必要信息，如您不提供手机号码，可能无法使用我们的服务。为帮助您完成注册，我们还将收集您的昵称与头像。此外，为确保账号安全，在我们识别出您注册、登录账号所使用的手机号码存在二次放号风险时，我们会将您的手机号码、账号注册/登录时间提供给通信运营商，以核验是否为二次放号。

二、我们如何共享、转让、公开披露您的个人信息

1. 共享

对于您的个人信息，我们不会与任何公司、组织和个人进行共享，除非存在以下一种或多种情形：

  1. 事先已得到您的授权；
  2. 您自行提出的；
  3. 向商业合作伙伴共享个人信息是提供服务所必要的。我们仅会出于合法、正当、必要、特定、明确的目的共享提供服务所必要的个人信息，并对信息数据的输出形式、流转和使用进行安全评估与处理。我们会对合作伙伴进行监督与管理，一旦发现其违规处理个人信息，将立即停止合作并追究其法律责任。您可以通过《第三方信息共享清单》了解合作第三方及数据处理情况；
  4. 与我们的关联公司进行必要共享。我们只会共享必要的个人信息，且共享受本政策所声明目的的约束；如关联公司改变个人信息处理目的，将再次征得您的授权和同意；
  5. 法律法规下的另一合法依据适用。
  6. 您可以基于 dooo0t 平台与第三人（包括不特定对象）共享您的个人信息或其他信息，但因您的共享行为导致的信息泄露、被使用及相关情况，由您自行承担相应责任。

当您使用音乐链接解析功能时，本产品会由客户端直接请求相关第三方公开域名，仅发送公开 URL 中的歌曲 ID 和必要的 UA / Referer，不上传用户身份信息。具体域名请查阅《第三方信息共享清单》。

2. 转让

转让是指将个人信息的控制权转让给其他公司、组织或个人。除非获取您的明确同意，否则我们不会将您的个人信息转让给任何公司、组织或个人。但下述情形除外：

  1. 事先已征得您的同意；
  2. 您自行提出的；
  3. 如果公司发生合并、分立、解散、被宣告破产，将可能涉及到个人信息转让，此种情况下我们会告知您接收方的名称或者姓名和联系方式并要求新的持有您个人信息的公司、组织继续受本政策的约束。若接收方变更个人信息处理目的、处理方式的，我们将要求其重新获取您的明示同意；
  4. 其他法律法规规定的情形。

3. 公开披露

公开披露是指向社会或不特定人群发布信息的行为。原则上，我们不会公开披露您的个人信息，但因公布账号中奖、处罚通知而展示必要的脱敏信息，或取得您的明示同意的情形除外。

4. 共享、转让、公开披露个人信息授权同意的例外情形

根据相关法律法规的规定，在以下情形中，我们可能在未事先征得您的授权同意的情况下共享、转让、公开披露您的个人信息：

  1. 为订立、履行个人作为一方当事人的合同所必需；
  2. 为履行法定职责或者法定义务所必需；
  3. 为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需；
  4. 为公共利益实施新闻报道、舆论监督等行为，在合理的范围内处理个人信息；
  5. 依照《个人信息保护法》规定在合理的范围内处理个人自行公开或者其他已经合法公开的个人信息；
  6. 法律法规规定的其他情形。

请您了解，根据现行法律规定及监管要求，共享、转让经匿名化处理的个人信息，且确保数据接收方无法复原并重新识别个人信息主体的，无需另行向您通知并征得您的同意。

三、我们如何存储和保护您的个人信息

1. 存储

存储地点：我们将从运营dooo0t产品中获得的个人信息存放于中华人民共和国境内。以下情形下，我们会确保在履行了法律规定的义务后，向中华人民共和国境外实体提供您的个人信息：

  1. 适用的法律有明确规定；
  2. 获得您的明确授权。

针对以上情形，我们会通过合同等形式确保以不低于本政策规定的程度保护您的个人信息。

存储时间：我们承诺始终按照法律的规定在合理必要期限内存储您个人信息（如有）。超出上述期限后，我们将删除您的个人信息或对您的个人信息进行匿名化处理。

如我们停止运营，我们将及时停止收集您个人信息的活动，会尝试将停止运营的通知以逐一送达或公告的形式通知您，并对所持有的您的个人信息进行删除或匿名化处理。

2. 保护

为了保护您的个人信息安全，我们将努力采取各种符合行业标准的安全措施来保护您的个人信息以最大程度降低您的个人信息被毁损、盗用、泄露、非授权访问、使用、披露和更改的风险。我们将积极建立数据分类分级制度、数据安全管理规范、数据安全开发规范来管理规范个人信息的存储和使用，确保未收集与我们提供的服务无关的个人信息。

您的账号具有安全保护功能，请妥善保管您的手机号码及登录验证码，切勿将验证码告知他人。我们将通过服务器备份及相关安全措施，努力确保您的信息不丢失、不被滥用和变造。

尽管有前述安全措施，但同时也请您注意不存在"完善的信息安全措施"。为协助防止安全事故的发生，我们已按照法律法规的规定，制定了预警机制和应急预案。如确发生安全事件，我们将及时将相关情况按法律要求的相关方式告知您，难以逐一告知个人信息主体时，我们会采取合理、有效的方式发布公告。同时，我们还将按照监管部门要求，主动上报个人信息安全事件的处置情况，紧密配合政府机关的工作。

当我们的产品或服务发生停止运营的情形时，我们会及时停止继续收集个人信息的活动。上述变更，我们将尝试以公告及相关形式通知您，并在合理的期限内删除您的个人信息或进行匿名化处理。

四、您如何管理您的个人信息

我们非常重视并尽力保障您对自己个人信息的相关权利。

1. 查阅、复制、更正、删除您的个人信息

您可以通过以下方式管理您的个人信息：

  1. 通过【首页-个人页】查询您的昵称与头像，点击【头像】进行修改；
  2. 通过【首页-个人页】查询已发布的作品，点击具体内容后，点击【分享】进行删除；
  3. 通过【首页-社区】查询已发布的评论，点击具体内容后，长按评论进行删除。

有下列情形之一的，我们将主动删除您的个人信息，您也有权请求我们删除：

  1. 处理目的已实现、无法实现或者为实现处理目的不再必要；
  2. 我们已停止提供产品或者服务，或者保存期限已届满；
  3. 您已明确撤回同意；
  4. 您有充分理由认为我们违反法律、行政法规或者约定处理您的个人信息；
  5. 法律、行政法规规定的其他情形。

2. 变更或撤回授权范围

您可以通过设备操作系统变更或撤回对设备权限的授权。我们将根据您的设置收集个人信息；撤回授权后，我们将不再收集与相关权限有关的信息，但这可能导致部分或全部功能不可用。您变更或撤回授权的决定，不影响我们此前基于您的授权进行的个人信息处理。

3. 附条件的个人信息转移权

如您需要将个人信息转移至其他平台、企业或组织，可以通过本政策第九条披露的方式联系我们。我们将审核您的请求，并在符合我国网信部门规定条件的情况下，为您提供转移相应个人信息的途径。

4. 约束信息系统自动决策

在一些业务功能中，我们可能仅依据信息系统、算法等非人工自动决策机制作出决定。如相关决定显著影响您的合法权益，您有权要求我们作出解释，我们也将提供适当的救济方式。

5. 近亲属权利

在符合相关法律要求的情况下，您的近亲属可以对您的相关个人信息行使上述查阅、复制、更正、删除等权利；您另有安排的除外。

6. 联系我们进行管理

出于安全和身份识别的考虑，您可能无法直接通过 dooo0t 的交互界面访问、更正或删除某些信息。如您确有必要访问、修改或依法要求删除该类信息，请按照本政策第九条提供的联系方式发送邮件。我们将在核验您的用户身份后及时处理。

五、您如何注销您的账号

您可以通过【首页-个人页-头像-更多】注销账号，注销申请提交后即时生效。账号注销后，除法律明确规定必须保留的个人信息外，您的个人信息将从 dooo0t 平台移除。
